# Hotcase 长图设计 Skill（守护案例 v1 沉淀）

一套经过实战验证的详情长图生产 SOP。核心能力：**同一组照片一键产出多套完整设计系统**、**全版式居中且对齐**、**1688 批发文案规范合规**。

> 组成：本 SKILL.md（SOP）+ `build_*.py` 构建脚本（仓库根目录）+ `skills/ecommerce-image-skills/`（外部 12 技能，末尾引用）。

---

## 0. Credo（优先于一切样式）

1. **图是最终交付物**：长图本身必须自带完整商品介绍文字，是可直接上架的成品。
2. **全部内容居中且对齐**（客户 2026-10 硬要求）：标题、胶囊、价格、分表、链条、CTA 全部围绕画幅中轴对称。
3. **渲染 → 看图 → 修**：每个构建必须肉眼质检全部版面（先抽看关键段，再看全段），发现问题立即修并重出。
4. **只新增，不覆盖**：Drive 上永远版本化新增，旧链接永不过期。
5. **每轮结束 git commit & push**：防工作区重置丢资产（血泪教训）。

## 2. SOP 主流程

### Step 1 · 产品身份锁（Identity Lock）
先看实体参考图，写一段"不可变更"身份描述（形状/配色/五官特征/配件），**逐字**并入每一张图的生成提示词，并把参考图同时作为 `images` 传入保持血统一致。

### Step 2 · 10 图拍摄清单（每案例必须 ≥10 张，足额）
按用途分解，一图一任务：
1. 主视觉主图（正面 3/4，棚拍无接缝底）
2. 多色并排（色卡版）
3. 手持/怀抱（真人尺寸感）
4. 脸部/关键件微距
5. 面料/材质微距
6. 日常物对比（钥匙串/矿泉水/手机）
7. 使用场景生活方式照
8. 全家福组照（套组感）
9. 礼盒/包装俯拍
10. 吊牌/织标/细节特写
> 补充图（买家秀、工厂实拍态）另算。

### Step 3 · 14 屏分屏规划（长图骨架）

- 只重建失败的资产。

### Step 7 · 交付
- 命名：`HOTCASE_LONG_<品名>_V<N>_<风格>.pdf/.jpg/_750.jpg`；

- git：`git add -A && commit && rebash push`（results/* 冲突一律取上游版本）。

## 3. 版式硬性规则（血泪修复记录）

1. **胶囊真垂直居中**：`y_c = y + H/2`（H=字高+上下内边距），文本在该点用 anchor `'lm'/'mm'` 绘制。**禁止** `y+21` 这类"约等于"偏移（就是这条 bug 导致每个胶囊文字偏高 14px）。
2. **居中一律先测宽**：`tw()` 实测文本宽，再 `(W - w)/2`；随行胶囊链条先累加总宽再卡中轴。
3. **数字带**：锚 `anchor='ls'` 基线对齐，每组(数字+单位)按列居中共基线；单位缩小着色。
4. **规格表**：中轴双列——key 端点 `W/2-32` 右对齐（rm），value 起点 `W/2+32` 左对齐（lm）。
5. **配色行**：胶囊顺序必须与照片中实物从左到右一一对应。
6. **出血文案带**：268px 高，胶囊/标题/副标题逐行居中；[顶/底]均可。
7. **标题 ≤2 行**（taste-skill 传承）；禁 eyebrow、禁 01/02/03 排序前缀、禁发丝细线、禁默认渐变。
8. **高亮块贴字形**：label/highlighter 用 `textbbox` 实测字形外框，上下各留 12-16 再画底块（禁拍脑袋 300..428）。
9. **旋转贴纸**：透明层绘制 → `rotate(-6°, expand=True)` 按新 bbox 求居中坐标，确保完全落进屏内（previous: 1068 起点被裁半张）。

## 4. 文案 SOP（1688 批发语境）

- **每屏结构**：胶囊标签（2-4 字）→ 主标题（≤2 行、口语化）→ 副标题（参数/卖点一行）。
- **痛点屏公式**：`烦恼短句 › 解法短句`（烦恼灰、解法粗黑），3 条封顶。
- **数字带**：3 个最硬数字（尺寸/克重/箱规），单位跟着数字走。
- **工艺 2×2**：面料 / 填充 / 工艺 / 安全，各 6-9 字短句。
- **规格表 10 行**：品名·尺寸·克重·面料·填充·配色·配件·工艺·箱规·定制。
- **批发关键词**：源头工厂 · X只/箱 · 混色 · 现货48h · 量大价优 · 代发全国 · 打样3-5天 · 100/300/500 起订。
- **CTA**：全宽色条双行（主诉求 + 详询客服 ›）。
- **广告法红线**：禁「最/第一/首/国家级/绝对」类表述；功效与安全等级（A类/食品级/保温时长）必须有证据才写。
