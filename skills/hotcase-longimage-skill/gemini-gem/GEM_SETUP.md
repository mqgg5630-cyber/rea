# Gemini Gem 安装卡 · 爆品长图设计总监

把 `hotcase-longimage-skill`（仓库 `skills/hotcase-longimage-skill/SKILL.md`）转成 Gemini「Gem（自定义助手）」可直接粘贴的形态。

## 1. Gem 创建页填写（复制即用）

| 字段 | 内容 |
| --- | --- |
| **名称 Name** | 爆品长图设计总监 · Hotcase Long-Image Director |
| **描述 Description** | 上传商品图片或资料，输出 1688/电商详情长图全套方案：产品身份锁 → ≥10 张拍摄与生图清单 → 14 屏逐屏文案+提示词 → 奶油/莫兰迪/多巴胺风格令牌 → 合规自检。内置「居中九戒」版式硬规则与广告法红线，批发文案语境，参数缺失一律标【待补】不臆造。 |
| **指令 Instructions** | 粘贴 `GEM_INSTRUCTIONS.md`**两条虚线之间**的全文 |

创建入口：Gemini 左侧「Gem 管理器 / 探索 Gem」→「+ 新建 Gem」。

## 2. 知识文件（可选，强烈建议挂）

Gem 支持上传知识文件增强上下文，建议挂两份：

1. `skills/hotcase-longimage-skill/SKILL.md`——完整 SOP（14 屏骨架、风格令牌库、9 条硬规则、广告法红线、守护 V3 案例快照），作为指令全文的"后端词典"；
2. 守护 V3 任意一套成品 JPG（如 `img8/LONG_SHOUHU_V3_A.jpg`）——让它回答"参照这个感觉"时有实物锚点。

挂了知识文件后，指令硬规则与 SKILL.md 冲突时以**指令框**为准（Gem 指令优先级更高）。

## 3. 首次使用示例（测试对话）

- 最小输入：「毛绒挂件，云朵帽小羊，13cm，300 只/箱混色，¥8.9 起，现货 48h，走 1688」→ 它应回 5 行身份锁请你确认；
- 图片输入：拖入商品图 + 「按多巴胺风做」→ 它应先复述身份锁再出 14 屏；
- 局部调用：「只给我痛点屏 3 条」→ 它应只出该屏 + QA 行。

## 4. 与仓库工作流的关系

Gem 负责**方案层**（身份锁/文案/屏规划/提示词）；把它输出的 14 屏规格交给仓库 `build_*.py`（PIL 参数化合成）+ 生图工具执行，质检与版本化交付仍按 SKILL.md §2 Step6/7 跑。Gem 版与仓库版同源：改 SKILL.md 的硬规则记得同步 `GEM_INSTRUCTIONS.md` 第五章。

## 5. 已知差异（为什么不能 1:1 搬）

- Gem 无代码执行环境 → "PIL 参数化合成"改写为"输出可直接进排版引擎的版式要点"；"渲染-看图-修"改写为"交付前对照硬规则自检+QA 三行"。
- 指令框若有长度上限，可按 `GEM_INSTRUCTIONS.md` 第六章末尾说明，把风格库从 3 套裁为所选 1 套，其余走知识文件。
