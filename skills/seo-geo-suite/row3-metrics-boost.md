# Row3 · 指标提升（供应链星级、采购指数4.0）

> 平台口径波动大：以下体检维度来自常见公开运营知识，**以店铺后台实时标签为准**。

## 短板定位树（先诊断再整改）

```
曝光低 → 标题相关性（→row2）/ 类目错挂 / 主图弱
点击低 → 主图1不够好（换风格重测）/ 价格带错位
询盘低 → 详情说服力（走14屏改版）/ 服务承诺缺
转化低 → 价格梯度缺档位 / 起订量过高 / 运费坑
评分低 → 发货时效 / 货描一致 / 售后响应时长
复购低 → 老客分层无运营动作 / 新品节奏断
```

## 常见快赢项（7 天内可动）

1. 48h 发货开关与真实履约对齐；超时单当日处理；
2. 全部在售品属性补到 100%；
3. 差评/低分单逐一回访留痕；
4. 消息分钟级响应（设自动应答+轮班）；
5. 在途滞销品降价清仓减库存权重拖累。

| W1 | 用 `prompts/store-checkup.md` 生成短板清单 | 体检假设表 |

## 体检报告模板字段

曝光/点击/询盘/下单/支付/退款/响应时长/发货超时率/评分 9 项，环比+同比+类目均值三列。
