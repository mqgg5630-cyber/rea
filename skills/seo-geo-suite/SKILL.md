# SEO-GEO 助手模块（自建复刻版）

对应模块矩阵「GEO布局」中 **运营获客** 四行。官方路径是 `1688生意助手 + 提示词 + 技能`（平台内置）、`自建智能体/skill`（我们这套）。本目录实现"自建"侧：四子技能 + 三份复用提示词模板。

> 口径声明：排名权重、星级构成、采购指数细节以 1688 平台后台实时规则为准；本套件提供**可执行 SOP 与自查模板**，非官方算法文档。

## 模块→技能映射

| 模块行 | 子技能 | 产物 |
| --- | --- | --- |
| 上新发品：发品+一键上架 | `row1-listing-publish/SKILL.md` | 发品字段清单 / 上架 SOP / 商品身份锁 |
| 商品优化：标题/属性/关键词/服务/相关性 | `row2-title-optimization/SKILL.md` | 30字标题公式 / 词库表 / 相关性自查 |
| 指标提升：供应链星级、采购指数4.0 | `row3-metrics-boost/SKILL.md` | 短板定位树 / 30天整改剧本 / 体检报告模板 |
| 数据分析：全店复盘、商品分析、店铺诊断 | `row4-data-review/SKILL.md` | 周报模板 / 漏斗诊断树 / 复盘 SOP |
| 提示词×3（可粘至任意 LLM/生意助手对话） | `prompts/*.md` | 标题优化 / 生意体检 / 数据复盘 |

## 与官方三件套的关系（怎么"想办法完成"）

1. **官方侧（在 Accio/1688 生意助手里跑）**：把 `prompts/*.md` 对口粘贴即可驱动「商品一键操作 / 1688商品标题优化工具能力 / 店铺生息体检」。
2. **自建侧（任何 LLM agent 跑）**：各子技能自含知识+模板+输出物规范，配合 `hotcase-longimage-skill` 出图、`taste-skill` 审美，把流量位素材与运营诊断打通。
3. **复用到 Accio 复刻架构**：映射 `ACCIO_REPLICATION.md` 的工具面——店铺授权=store_auth_gateway/discover_store_accounts，体检流程=skill 工作流，报告=dashboard_report/weekly_report 通道。

## 工作流（每次运营动作）

入参（店铺 ID / 类目 / 商品池导出）→ 选行 → 跑子技能 → 输出模板产物 → 需要上架/改标题时人工或 RPA 执行 → 行3 复盘改版。

## 交付检查

- [ ] 输出物齐全（清单/报告不带缺口注释"待补"）；
- [ ] 文案过广告法红线（见 hotcase-longimage-skill §4）；
- [ ] 未越权宣称平台规则（数字类均标注"以后台为准"）。
