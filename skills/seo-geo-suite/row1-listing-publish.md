# Row1 · 上新发品（发品+一键上架）

## 发品字段必经清单（1688 批发语境）

| 字段 | 要求 | 自查 |
| --- | --- | --- |
| 类目 | 平台最细类目，不投机大词类目 | ✔ |
| 标题 | 30 字满编，见 row2 公式 | ✔ |
| 主图 | 1 白底 + 2 场景 + 1 卖点 + 1 规格（5 张起） | ✔ |
| 详情长图 | 走 `hotcase-longimage-skill` 14 屏流程 | ✔ |
| 属性 | 品牌/材质/规格/颜色全部勾选至 100% | ✔ |
| 价格梯度 | ≥3 档（起订量/中档/大单） | ✔ |
| 运费模板 | 与仓发地址一致 | ✔ |
| 服务承诺 | 48h 发货/破损包赔明确勾选 | ✔ |

## 一键上架 SOP

1. 商品身份锁（自 hotcase skill Step1）——形状/配色/规格/卖点一句话锁住；
2. 按清单填字段 → 标题先过 row2 优化器再定稿；
3. 主图 5 张 + 详情 1 套（风格随机抽 A/B/C 测 CTR）；
4. 定价梯度提交审核；24h 后回查状态与曝光种子流量；
5. 记录 `publish_log.csv`：品名/类目/标题/梯度/上架时间/风格标签。

## 使用提示词

发品草稿生成 → 粘贴 `prompts/title-optimizer.md` 出 5 候选标题，选 1 上架，其余进 A/B 池。
